# Timing recovery study: system overview

This study adds a reproducible symbol-timing experiment to the existing BPSK
project. It uses the same received waveform for the Gardner loop and the
Kalman-based timing tracker so that the loop update is the principal variable.

The simulated chain is:

`random bits → BPSK → transmit RRC → timing offset and clock mismatch → AWGN → matched RRC → timing tracker → hard decisions`

The simulation isolates symbol synchronization. It does not implement the
complete packet, FEC, carrier recovery, DAC/ADC, or hardware chain shown in the
original project proposal.

## Files

- `timing_recovery_comparison.py`: simulation and plotting program.
- `results/config.json`: parameters and scenarios used for the included run.
- `results/summary.csv`: per-method, per-scenario averages.
- `results/*.png`: plots generated by the simulation.

See the root README for installation and run instructions. Additional notes
describe the two trackers, scoring measures, tested conditions, and limitations.
